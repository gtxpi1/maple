# 08 — UI/UX Design Guide (v0.1, reorganized)

## Principle

Familiar to use. Original by design.

## Focus Areas

- Fast posting flow
- Responsive layout
- Accessible navigation
- Theme presets
- Mobile-first
- Low learning curve
- Original branding and assets
